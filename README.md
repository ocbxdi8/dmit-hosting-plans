# 海外建站主机：免备案即时上线，从机房、线路到套餐预算，新手也能选对第一台服务器

搜"海外建站主机"的人，问题往往很具体：域名解析好了，服务器还没影，国内机房又要等备案审核；或者站点已经跑起来，打算换到境外，却在一堆 CN2 GIA、CMIN2、国际 BGP 的名词里彻底迷路。

这篇文章不打算再重复一遍"海外主机免备案"这种谁都知道的结论。重点放在三件事上：你的站适合放哪个机房、哪条线路、多大配置；预算大概落在什么区间；以及在 DMIT 这个常被拿来讨论的选项里，具体该怎么选套餐。

## 免备案只是入场券，真正决定体验的是这三件事

先纠正一个很常见的误解：把服务器搬到境外，不等于访问速度问题就自动解决了。免备案只是省掉了 7 到 20 个工作日的审核等待，购买后几分钟就能部署，域名解析生效即可访问。剩下的体验好坏，全看下面几点。

**访客在哪里，机房就该在哪里。** 面向欧美客户的外贸站，美国机房是合理选择，跨洋链路对欧美访客反而更快；但如果你的主要读者在中国大陆，把站放在美国东岸，首屏加载慢一两秒是常态，这时候要么选美西节点，要么干脆用香港、日本机房。

**线路比配置更能决定体感。** 同样是 2 核 2G 的机器，标称端口都是 1Gbps，实际从上海电信晚高峰跑出来的速度可能是 12Mbps，也可能是 71Mbps。差距不在硬件，在回国的路由上。所谓"优化线路"，指的是服务商和国内三大运营商之间有直连或专用通道，能把晚高峰的丢包和绕路压下来。

**流量和超额策略，比月费更容易埋坑。** 很多便宜套餐写着"无限流量"，实际条款里藏着一句"合理使用限制"，一旦持续跑满就被掐到 1Mbps。也有服务商的做法是把话说在前面：高速流量用完后降速继续跑，不停机。后者对博客和展示站其实更友好，因为你大概率跑不到那个额度，但真到了也不会突然断站。

顺带把风险也说清楚。免备案不等于没人管你。网站内容违法，无论服务器在哪，运营者照样要担责；如果你的站点内容触发平台规则，还可能出现域名解析被干扰、IP 被墙这类情况。另外百度对未备案的海外站点抓取频率和权重通常偏低，如果你的主要流量来源是百度搜索，这一点必须提前权衡。

## 按访客位置倒推：机房和线路怎么搭

把上面几条落到具体选择上，逻辑其实很清晰。

访客主要在中国大陆，且对加载速度有硬要求，看香港机房。香港到内地物理距离近，配合 CN2 GIA 这类线路，三网平均延迟可以压到 40–50ms 区间，体验接近国内节点。代价是价格贵，同配置往往比美国机房高出好几倍。

访客在国内但预算有限，退一步看美西或日本。美西洛杉矶是国内访问延迟相对可控的美国节点，日本东京到上海方向延迟也不高，是香港之外比较常见的折中方案。

访客主要在海外，选国际线路就行。纯国际 BGP 不针对中国大陆做优化，价格明显低一档，端口和流量反而给得更宽松，适合外贸展示站、API 后端、备份和 CI/CD 这类场景。

这里要提醒一句：**不要只看价格档，先确认自己属于哪一类。** 有人在香港 T1 上踩过坑——T1 是国际线路，不做中国优化，电信用户买回来发现延迟比美国机房还高，这种情况并不少见。

## DMIT 为什么总出现在"海外建站主机"的讨论里

DMIT 是近几年在中文站长圈里被反复提到的一家 VPS 服务商，主要卖洛杉矶、香港、东京三地机房的 KVM 虚拟服务器，线路按三档划分。关于它的成立时间，公开资料里有 2017 和 2018 两种说法，注册地多指向美国纽约，这个细节对选套餐没影响，知道它是一家运营了七八年的商家就够了。

它被拿来推荐的理由，集中在几个可验证的点上：

- 线路分层清楚。Premium 走 CN2 GIA 一类的高端优化线路，Eyeball 走 CMIN2 / AS9929 这档"尽力而为"的中国优化，Tier 1 是纯国际 BGP。三档对应三种预算和三种使用场景，不用猜。
- 硬件平台是 AMD EPYC，配 NVMe / 企业级 SSD。目前主要覆盖 AS3（EPYC 7003）、AN5（EPYC 9005）两代平台，同配置的 AN5 版本会贵一些，磁盘 IO 和单核性能也更强。
- 流量超额后降速不停机。不同套餐的超额限速从 4Mbps 到 1Gbps 不等，站点不会因为跑完流量直接停机。
- 付款方式对国内用户友好。支持支付宝、PayPal、信用卡，有中文客服，不用为了一张外币卡折腾。
- 换 IP 政策相对宽松。多个第三方整理资料都记录为每 15 天可免费更换一次被墙 IP，其他情况按次收费。

需要提前知道的是，DMIT 的库存波动比较明显。热门机型比如洛杉矶 Pro 的 MINI、MICRO，以及香港、日本的部分配置，阶段性售罄是常事。看中某款建议尽快下单，别拖到补货周期结束。

顺便说清楚一个容易误判的地方：DMIT 的洛杉矶 AS3 平台目前官方标注仍在持续优化阶段，可能出现磁盘性能和 SLA 低于成熟平台的情况。如果你的业务对磁盘 IO 敏感，或者要跑正式生产环境，选 AN5 平台更稳妥。

## 按场景对号入座，别再纠结"哪个最好"

不存在通吃的答案，只有和你情况匹配的选项。下面几种典型情况，可以直接照抄。

**纯外贸展示站、访客在欧美。** 选洛杉矶 Tier 1。TINY 月付 $6.90，1 核 1G / 20G 硬盘 / 2TB 月流量，跑一个 WordPress 企业站绰绰有余；预算明确想省，WEE 年付 $36.90 折下来每月约 $3.08，是全系门槛最低的入场价。省下的钱拿去买 CDN，比升级配置划算得多。

**访客主要在中国大陆，且吃 SEO 排名。** 这是最该花钱的场景。洛杉矶 Premium 的 TINY 月付 $10.90，1 核 2G 配 CN2 GIA 三网回程，是高端线路里最便宜的入门口；要做正式的品类内容站或电商独立站，建议从 STARTER（$34.90，10Gbps / 3TB）起步，TINY 的 1TB 流量在图片较多的站点上并不宽裕。

**预算敏感但想兼顾国内访问。** 看洛杉矶 Eyeball。同样是 $10.90，EB 版给到 2Gbps 端口和 1.5TB 流量，比 Premium 同价位宽松一档，代价是回程走 CMIN2 / AS9929 而不是 CN2 GIA。移动和联通用户对这条线路的体感往往比电信用户更好。

**东南亚或跨境业务，需要低延迟。** 香港机房首选，但香港 Premium 的 TINY 就要 $39.90 / 月，成本是洛杉矶的将近四倍。如果只是要一个香港 IP 做中转、区域分发或者异地备份，香港 Tier 1 的 TINY（$6.90 / 月）能省下大量预算——前提是你接受它不做中国优化。

**吃流量的下载站、图床、备份节点。** 香港 T1 的 LARGE 给到 64TB 月流量、$99.90 / 月，这个量级在同价位里不太好找替代；洛杉矶 T1 的 MICRO（16TB / $32.90）是更便宜的入门选择。

**数据库密集或对磁盘 IO 敏感。** 优先选 AN5 平台。以香港 Premium 为例，AS3 的 MICRO 是 $179.90，AN5 的 MICRO 是 $159.90，硬件更新、价格反而更低，这类情况可以直接选新一代平台。洛杉矶 AS3 官方标注仍在优化阶段，正式生产环境建议避开。

## 下单前值得确认的几件事

**优惠码要现场验证，不要照着攻略抄。** DMIT 的促销主要以阶段性活动的形式出现，包括年付、季付的循环折扣，以及库存补货时的特价机型。公开渠道流传过不少优惠码，比如针对洛杉矶 Eyeball 非月付订单的循环折扣码，但这类代码有明确的产品线和付款周期限制，过期也很快。结算页有 Validate Code 入口，填进去验证通过再用，没通过就说明不适用于你选的套餐。

**别忽略超额限速的具体数值。** 表格里的"流量用完后"一列才是长期成本的关键。4Mbps 够不够用，取决于你的站点类型：纯文字博客没问题，带大量图片就不行。这一列比月费更值得认真看一遍。

**库存是实时变量。** 热门机型售罄是常态，恢复时间通常不公开。如果你看到某个套餐显示缺货，同线路的相邻档位或者 AN5 版本往往还有货，可以作为备选。

**退款和 IP 政策，去官方条款确认。** 第三方整理资料里能看到 3 天全额退款、30 天按比例退款、每 15 天免费更换被墙 IP 这类说法。这些属于服务条款范畴，不同机型可能有差异，下单前在商品页和 TOS 里核对一遍，比事后扯皮省事。
